# Matriz de evidencia
| Campo | Contenido requerido |
|---|---|
| Decisión | Regla acordada |
| Fuente | Módulo, DDL o contrato |
| Implementación | Verificada / pendiente / no implementada |
| Prueba | Ruta, comando, resultado |
| Fecha | Última verificación real |

No convertir fecha de edición de la skill en fecha de verificación del código.
